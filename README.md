# Yahboom Gamepad

Yahboom GHBit gamepad driver for the micro:bit (v2): the thumb-stick direction and continuous position sensors, the colored-button sensor, the received-packet decoder, and the position-to-packet radio encoding.

Add this library to a project's dependencies:

```
gh:mindcraft-lang/lib-yahboom-gamepad@0.2.0
```

Then import from it:

```ts
import { } from "@lib/mindcraft-lang/lib-yahboom-gamepad";
```
